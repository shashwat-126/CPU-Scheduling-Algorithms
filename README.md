# CPU Scheduling Algorithm Visualizer

</div>


## 🎯 Aim
A Python GUI-based tool that simulates and visualizes major CPU scheduling algorithms:
- FCFS (First Come First Serve)
- SJF (Shortest Job First)
- Priority Scheduling
- Round Robin

## 💡 Features
- User-friendly Tkinter interface
- Add processes dynamically
- Select algorithm from dropdown
- Optional quantum for Round Robin
- Visual Gantt chart using Matplotlib
- Calculates turnaround and waiting times (can be extended)
